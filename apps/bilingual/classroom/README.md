# Classroom pack — bilingual activity

Four files, read in this order, that tell the bot who to be.

| File | Purpose |
|---|---|
| `01-context.md` | What the participants share: the course, the room, the vocabulary |
| `02-bot-scope.md` | Register rules, tells to avoid, identity handling, safeguards |
| `03-personas.md` | The personas, one drawn per conversation and held for the round |
| `04-writing-samples.md` | Real participant register, paraphrased |

**Three of these are placeholders.** `02-bot-scope.md` is usable as it stands; its
safeguards section applies regardless of what replaces the others.

Persona headings must keep the exact `## Persona X — Name` format — the loader splits
the file on them. Add or remove personas freely; the console lists whatever it finds.
