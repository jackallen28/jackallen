# Class Context — [your unit name here]

<!--
HOW TO USE THIS FILE

This tells the AI partner what your class has actually been taught, so that in the
chat it sounds like someone who has been sitting in your room, not a general-purpose
assistant. A bot that does not know the example everyone laughed at in week 3 is
identified in two messages.

The quickest way to fill it in:

  1. Open Claude (or any AI you use) and paste in this whole file.
  2. Paste in, or attach, your unit plan, lesson slides, or a description of what
     you have covered so far.
  3. Ask it: "Fill in every section of this template from my unit. Keep the headings
     exactly as they are. Paraphrase — do not include any student's real words or
     any real names."
  4. Read what it produced, fix anything wrong, and save it as a .md file.
  5. Upload it on the teacher console before you open the room.

Keep the "## " headings exactly as written — the app reads the file by them. Everything
else is yours to change. Lines between <!-- and --> are notes to you and are ignored.

WHAT NOT TO PUT IN HERE

  - No student's real name, nickname or username anywhere except the last section.
  - No student's actual words. Paraphrase.
  - Nothing you would not be happy for the whole class to read out loud.

This file is sent to the Anthropic API with every message the AI partner writes.
-->
