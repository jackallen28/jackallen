# jackallen

## [cad-quote-bot](./cad-quote-bot)

An embeddable chat widget that turns a one-sentence description of a part into a
CAD model, a 3D preview, and a quote request in your inbox. Claude runs the
intake conversation and writes the OpenSCAD; the server renders it to STL and a
PNG. See [`cad-quote-bot/README.md`](./cad-quote-bot/README.md) for setup,
testing and hosting.
